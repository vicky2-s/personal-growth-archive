# 05 · GitHub 上传与部署步骤

## 1. 创建仓库

1. 访问 https://github.com ，登录。
2. **New repository**：
   - 名称如 `personal-growth-archive`
   - 设为 **Public**（GitHub Pages 免费版需公开，私有需 Pro）
   - 不勾选初始化 README（我们已有文件）

## 2. 上传代码（命令行方式）

```powershell
# 在本项目根目录（博物馆讲解大赛2026）执行
git init
git add .
git commit -m "feat: 人生档案馆 MVP v1"

git remote add origin https://github.com/<你的用户名>/personal-growth-archive.git
git branch -M main
git push -u origin main
```

> 注意：`config.js` 中的 anon key 是公开密钥，放在前端仓库是安全的；
> 数据库密码、service_role key 千万不要提交。

## 3. 开启 GitHub Pages

1. 仓库 **Settings → Pages**。
2. **Source** 选择 `Deploy from a branch`。
3. **Branch** 选择 `main` / 根目录 `/ (root)`。
4. 保存后等待部署，得到地址 `https://<用户名>.github.io/personal-growth-archive/`。

## 4. 更新 Supabase 站点 URL

部署后，把 GitHub Pages 地址填到 Supabase：
- **Authentication → URL Configuration → Site URL**

## 5. 后续更新

```powershell
git add .
git commit -m "update: xxx"
git push
```
GitHub Pages 会自动重新部署。
