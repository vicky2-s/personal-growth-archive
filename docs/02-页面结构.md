# 02 · 页面结构设计

## 1. Dashboard 首页

### 欢迎区域
- 问候语：`你好，{display_name} 👋` + `欢迎回到你的人生档案馆。`
- 4 个统计卡片：
  - 已记录项目 / 已归档文件 / 能力证据 / 已解锁成就

### 当前进行中的项目（卡片列表）
- 名称、进度条（基于项目内证据/贡献数相对进度）、开始时间、最近更新时间
- 点击进入项目详情

### 能力概览（六大领域）
- 每个领域：图标 + 证据总数 + 相对进度条 + "N 项能力证据"
- 底部说明文字：*"能力成长基于真实项目和实践证据积累，不代表专业测评结果。"*

### 最近成长
- 最近新增的项目 / 文件 / 能力证据 / 成就

## 2. 项目管理

### 项目列表
- 顶部：新建项目按钮 + 状态筛选（进行中 / 已完成 / 暂停 / 全部）+ 搜索
- 项目卡片：名称、类型、状态徽章、时间、标签、文件数、证据数

### 新建 / 编辑项目表单
- 名称、类型、状态、开始/结束时间、描述、标签、封面（可选）

### 项目详情（核心页）
1. **基本信息**：名称 / 时间 / 类型 / 状态 / 描述 / 标签
2. **我的角色**：角色列表（可增删）
3. **我的贡献**：贡献列表（可增删）→ 每项可「关联能力」生成证据
4. **项目成果**：成果列表（可增删，如最终讲解稿、获奖证书）
5. **相关文件**：该项目的文件网格 + 上传入口
6. **能力成长**：该项目产生的能力证据
7. **个人反思**：学到什么 / 困难 / 改进（可多条）

---

## 3. 文件档案系统

### 档案页
- 上传按钮（拖拽 + 点击）
- 筛选栏：年份 / 项目 / 文件类型 / 标签 / 能力
- 搜索框（搜索文件名、描述、标签、项目名）
- 文件列表/网格：图标、名称、类型、项目、标签、重要程度、上传时间
- 「未分类文件」为虚拟分类（`project_id` 为空）

### 上传流程（不强制先建项目）
1. 选择/拖拽文件 → 默认进入「未分类」
2. 上传成功后弹层显示：文件名、所属项目（未分类）、标签编辑
3. 可立即「选择项目」或「新建项目」
4. 支持：查看、下载、删除、移动到其他项目、添加标签、改重要程度

---

## 4. 能力地图

### 能力总览
- 六大领域卡片，点击进入领域

### 领域详情
- 该领域下 5 项能力，每项：名称 + 证据数 + 相对进度条

### 能力详情
- 能力等级（Level 0~5）+ 有效证据数量
- 所有证据按年份分组：
  ```
  2026
  ✓ 全国高校讲解比赛
  ✓ 博物馆讲解工作
  2025
  ✓ XXX活动
  ```
- 「添加证据」入口（选择项目 + 贡献 + 行为描述 + 时间）

---

## 5. 成长时间轴

- 按时间倒序展示项目节点（也可展示独立经历）
- 筛选：年份 / 项目类型 / 能力（如"所有提升公众演讲的经历"）
- 点击节点进入项目详情

---

## 6. 成就系统

- 已解锁成就（彩色）+ 未解锁（灰色）
- 每个成就：图标、名称、描述、解锁条件、解锁日期、关联项目
- 按分类（表达 / 学习 / 数字）分组
